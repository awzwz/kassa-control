## 5. Архитектура и модели
Caddy (HTTPS) → FastAPI → очередь задач в SQLite → 2 обработчика. Конвейер обработчика: ffmpeg (5 кадров/с) → YOLOX-s в ONNX Runtime (люди и предметы; раз в секунду проход 960×544 ради мелких предметов) → ByteTrack (треки людей) → сигналы (стол и ноутбук как опорные предметы, кассир = самый длинный трек у рабочего места, моменты вставания, ухода, входа посетителей) → правила по четырём моментам (уход, вход, обслуживание, рабочее место) → описание из каталога норм → 1–3 кадра-доказательства. Все пороги заданы в долях роста человека, а не в пикселях, чтобы переносились на другой ракурс. Сторож времени: через 240 с отдаётся лучший частичный результат; при очереди ≥ 3 видео включается экономный режим (4 кадра/с).

Модели и лицензии: YOLOX-s (Apache-2.0), trackers/ByteTrack (Apache-2.0), supervision (MIT), ONNX Runtime (MIT), OpenCV (Apache-2.0), FastAPI/uvicorn (MIT), Caddy (Apache-2.0). Обучения на данных банка не проводилось; данные использовались только для настройки порогов на ноутбуке участника и на сервер не загружались. Внешние AI-сервисы не используются; лица не распознаются; видео удаляется после анализа.

## 8. Ограничения и известные ошибки
- На 40 обучающих роликах: найдено 11 из 21 нарушений, 0 ложных тревог на 19 чистых роликах; тип совпал у всех найденных; медианное расхождение по времени 0,6 с.
- Не распознаются состояния сейфа, ключа и двери, порядок пересчёта, предъявление документа, использование детектора банкнот — для них нужен отдельный детектор, в интерфейсе они помечены «не проверялось».
- Предметы меньше ~15 пикселей на исходном кадре и закрытые руками или мебелью могут быть не распознаны; детектор обучен на COCO, поэтому пачка денег видна как «телефон/книга», сумка — как «сумка».
- Сервер на 4 vCPU без GPU: ролик 145 с обрабатывается ~190 с; при 5 одновременных роликах по 60 с худшее время 154 с. При нехватке времени — частичный результат с пометкой.
- Решения проверяющего хранятся в браузере, не на сервере. Результаты хранятся 24 часа, видео удаляется сразу после анализа.
